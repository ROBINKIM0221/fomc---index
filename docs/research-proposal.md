# 연구 제안서: AI 에이전트 기반 FOMC 통화정책 스탠스 지수의 고도화 및 실증 검증

> 인수인계: 기존 FinBERT 파이프라인(전임자) → AI 에이전트 활용 연구(금년)

---

## 1. 연구 배경 및 동기

연방공개시장위원회(FOMC)는 연 8회 회의에서 **성명서(Statements)** 와 **의사록(Minutes)** 을
발표하며, 이 문서의 "어조(tone)"는 금융시장에 즉각적이고 광범위한 영향을 미친다.
시장 참여자들은 문서가 **매파적(hawkish, 긴축)** 인지 **비둘기파적(dovish, 완화)** 인지를
빠르게 판독하려 하며, 이를 정량화하려는 시도가 오랫동안 이어져 왔다.

선행 시스템(본 저장소)은 사전학습 금융 감성모델 **FinBERT**(`ProsusAI/finbert`)로
문장별 긍/부정을 분류해 0~100 감성지수를 산출하고, GitHub Actions로 매일 자동
갱신·배포하는 **서버리스 파이프라인**을 완성했다. 그러나 학술 연구로 발전시키기에는
다음과 같은 방법론적 한계가 존재한다.

---

## 2. 문제 정의 (기존 시스템의 한계)

| # | 한계 | 설명 |
|---|------|------|
| L1 | **감성 ≠ 통화정책 스탠스** | FinBERT는 뉴스·실적 기반 *감성* 모델로, FOMC 특유의 매파/비둘기파 *정책 스탠스* 를 직접 측정하지 못한다. |
| L2 | **정보 손실** | softmax 확률을 버리고 argmax 라벨(-1/0/+1)만 사용하며, 단순 평균으로 집계해 문장 중요도·강도를 반영하지 못한다. |
| L3 | **맥락 무시** | 문장을 독립적으로 분류하여 부정·조건·미래시제("인플레가 완화되지 않으면 추가 긴축")를 오판한다. |
| L4 | **검증 부재** | 산출된 지수가 실제 시장 반응을 설명·예측하는지에 대한 실증 검증이 전무하다. |
| L5 | **설명불가** | 점수만 제시될 뿐, 왜 그 점수인지에 대한 근거(근거 문장·논리)가 없어 해석·신뢰가 어렵다. |

---

## 3. 연구 목표

**대주제:** FinBERT 단순 감성분석을 **LLM 에이전트 기반 설명가능 통화정책 스탠스 지수**로
고도화하고, 시장 데이터로 그 타당성을 **실증 검증** 한다.

세부 목표:
- **O1.** FOMC 문서의 매파/비둘기파 스탠스를 맥락 추론으로 측정하는 LLM 에이전트 구축 (→ L1, L3)
- **O2.** 점수와 함께 근거 문장·확신도·회의 간 톤 변화를 제시하는 설명가능 지수 (→ L2, L5)
- **O3.** FinBERT 기준선 대비 LLM 에이전트의 성능을 동일 조건에서 비교 (→ 방법론 정당화)
- **O4.** 지수의 시장 예측력(국채금리·주가)을 이벤트 스터디로 검증 (→ L4)

---

## 4. 연구 방법

### 4.1 방향 A — LLM 에이전트 기반 스탠스 분석 (구현됨: `builder/sentiment_llm.py`)

- Claude 에이전트가 각 문장을 `dovish(+1)/neutral(0)/hawkish(-1)` 로 분류하되,
  부정·조건·시제 등 **맥락을 추론** 한다.
- 문서 단위 분석(`analyze_document`)은 다음을 함께 반환한다:
  - 연속 스탠스 점수(-1.0 ~ +1.0), 확신도(confidence)
  - **근거 문장 인용**(key_signals)과 사유(reason)
  - 직전 회의 대비 **톤 변화**(tone_shift)
- 기술: 구조화 출력(`messages.parse`), adaptive thinking, 프롬프트 캐싱.

**확장 아이디어(선택):**
- *멀티 에이전트 토론* — 매파/비둘기파 에이전트가 동일 문서를 두고 토론, 중재 에이전트가 합의 점수 도출(위원 의견 분포 모사).
- *RAG* — 과거 전체 FOMC 문서를 검색 컨텍스트로 제공해 상대적 톤 변화 정밀화.

### 4.2 방향 B — FinBERT/LLM 비교 실험 (인프라 구현됨: `builder/backend.py`)

- 환경변수 `SENTIMENT_BACKEND` 로 두 백엔드를 토글하여 **동일 입력**에 대해
  결과를 산출, 직접 비교한다.
- 비교 항목: 라벨 일치율, 지수 시계열 상관, 시장 예측력(4.3), 인간 평가와의 일치도.

### 4.3 방향 C — 실증 검증 / 이벤트 스터디 (구현됨: `builder/backtest.py`)

- 각 FOMC 발표일을 이벤트로 설정, 발표 전후(t-1 → t+1) 시장 변화를 측정한다.
  - 10년물 국채금리(`^TNX`), S&P500(`^GSPC`) — `yfinance`(무료).
- **가설 검정:**
  - **H1.** dovish↑ → 국채금리 변화↓ (음의 상관 기대)
  - **H2.** dovish↑ → 주가수익률↑ (양의 상관 기대)
- 산출: 상관계수, p-value, 방향 적중률, 회귀.

## 5. 평가 지표

| 구분 | 지표 |
|------|------|
| 분류 품질 | 인간 라벨(소표본 골드셋) 대비 정확도·F1, 기준선(FinBERT) 대비 향상폭 |
| 지수 타당성 | 시장 변수와의 상관계수·p-value, 방향 적중률(H1/H2) |
| 예측력 | 발표 전 정보만으로 발표 후 시장 변화 예측 시 적중률·정보계수(IC) |
| 설명가능성 | 인용 근거의 적절성에 대한 정성 평가 |
| 강건성 | 기간 분할(코로나 전/후 등) 하위표본 일관성 |

## 8. 기대 기여

- 단순 감성을 넘어 **설명가능한 통화정책 스탠스 지수** 라는 새로운 측정 도구 제시.
- LLM 에이전트가 전통 사전학습 분류기(FinBERT)를 **언제·얼마나** 능가하는지에 대한 실증 근거.
- 텍스트 기반 정책 신호의 **시장 예측력** 에 대한 정량 검증.
- 비용 0의 서버리스 파이프라인으로 **재현 가능·지속 갱신** 되는 공개 연구 인프라.
